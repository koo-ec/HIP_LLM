# Support

## Questions and reproducibility help

Use [GitHub Discussions](https://github.com/koo-ec/HIP_LLM/discussions) if enabled, or open a question using the repository's issue templates.

Before asking for help, please include:

- operating system and Python version;
- installation method;
- the exact command run;
- the complete error message with secrets removed; and
- whether you used published-numerics, strict-exact or live mode.

## Bugs and feature requests

Use the structured issue forms under **Issues → New issue**. Reproducibility mismatches have a dedicated template.

## Security reports

Do not use a public support channel for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

This is a research software project maintained on a best-effort basis; response times are not guaranteed.
